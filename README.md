# Artificial Neural Networks & Deep Learning (ANN-DL)

Welcome to the **ANN-DL** repository! This repository contains laboratory implementations focusing on core Python programming structures and vector/matrix manipulations using NumPy, serving as the foundational building blocks for Neural Networks and Deep Learning algorithms.

---

## 📂 Lab 1: Python Core Foundations
This lab focuses on the practical implementation of core Python programming structures, data structures, and Object-Oriented Programming (OOP) concepts.

### 📝 Key Tasks Covered:
* **Task 1: Basic Variables & Operations** – Variable initialization, dynamic typing inspection with `type()`, assignment operators, and value-swapping patterns.
* **Task 2: List Manipulations** – Dynamic manipulation of collections utilizing `.append()`, `.insert()`, `.pop()`, and list sorting mechanisms.
* **Task 3: Tuples & Dictionaries** – Demonstrating data immutability concepts in Python tuples and associative key-value mapping architectures in dictionaries.
* **Task 4: List Slicing** – Advanced extraction, step slicing, and data-reversing methods.
* **Task 5: String Formatting & Loops** – String interpolation (`f-strings`), text splitting tokenization, and string parsing vowel counters.
* **Task 6: Conditional Statements** – Implementation of complex conditional trees (`if-elif-else`), logical evaluation flags (`and`/`or`), and nested loops for mathematical edge cases (e.g., leap years).
* **Task 7: Loops & Control Flow** – Managing iteration loops utilizing `continue` and `break` controls, constructing multiplication matrices via `while` structures, and loop arithmetic aggregations.
* **Task 8: Functions & Scope** – Designing modular components using default argument mapping, return states, and evaluating pass-by-reference mechanics in lists.
* **Task 9: Object-Oriented Programming (OOP)** – Construction of parent classes, instantiation, object method mapping, and structural child inheritance via `super().__init__()` alongside custom method overriding.

---

## 📂 Lab 2: Mathematical Computations with NumPy
This lab focuses on high-performance vector operations, matrix algebra, multi-dimensional array manipulation, and analytical computations utilizing the NumPy library.

### 📝 Key Tasks Covered:
* **Task 1: Vector Fundamentals** – Array structural declarations, dimension/shape analysis, broadcasting operators, and vectorized statistical mathematical computations (`np.mean`).
* **Task 2: Matrix Allocations** – Multi-dimensional matrix initialization, memory array sizing, template initialization (`np.zeros`), and index-targeted row replacements.
* **Task 3: Arithmetic & Reductions** – Matrix summation overlays, performance difference mapping, and programmatic indices tracking through `np.argmax`.
* **Task 4 & 5: Dot Products & Dimensions** – Implementing linear algebraic operations using `np.dot` over vectors and matrix spaces, along with code annotations exploring dimension matching safety rules.
* **Task 6: Randomization & Multidimensional Indexing** – Generating integer matrix structures (`np.random.randint`), multi-axis target array indexing, and layout alteration tracking.
* **Task 7: Advanced Matrix Slicing** – Segmenting sub-matrices, alternative index step extractions, and trailing index subset arrays.
* **Task 8: Pseudo-Random Seeds** – Establishing controlled environment bounds using `np.random.seed` to demonstrate variance control in Gaussian distributions (`np.random.randn`) and random decimal uniform configurations.
* **Task 9: Matrix Transposition** – Evaluating spatial matrix inversions via `.T`, programmatic inversion double-check workflows, and shape alignment workflows for linear transformations.
